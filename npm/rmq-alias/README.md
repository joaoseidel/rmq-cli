# @joaoseidel/rmq

An alias for [`rmq-cli`](https://www.npmjs.com/package/rmq-cli) — a full-screen
terminal browser for RabbitMQ.

```bash
npx @joaoseidel/rmq
```

It contains no code of its own: it depends on the identical version of `rmq-cli`
and runs that package's `rmq` binary. Either name gets you the same app.

Documentation lives in the [main repository](https://github.com/joaoseidel/rmq-cli).
